# 心动同频 · 恋爱默契测试

一个双人同屏触屏小游戏：3-2-1 倒计时后，两人各自按住屏幕两侧的圆圈约一秒再一起松手，按「同时按下、按压时长、落点精准」三项算出默契值。

## ✨ 功能特性

- **双人同屏对抗协作**：一部手机两人同时玩，粉色圆圈是 TA1、蓝色是 TA2，基于多点触控识别各自手指
- **三项默契评分**：心动同步·按下时间差（40%）+ 节奏默契·按压时长差（30%）+ 位置精准·落点偏差（30%），合成总默契百分比
- **五档评语**：从「天作之合」到「缘分需要浇灌」，按得分给出称号与寄语
- **按压数据明细**：各自的反应时间、按压时长、落点偏差，以及两人的时间差 / 时长差
- **移动端优先**：全屏布局、禁用缩放与选中，倒计时与超时重试机制完备

## 🚀 使用方法

在手机（或触屏设备）浏览器中直接打开 `index.html`：点击开始 → 倒计时后两人同时按住各自的圆圈约 1 秒 → 一起松手 → 查看默契结果，可「再来一局」。

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript，零依赖、零构建、单文件
- Touch Events 多点触控（兼容鼠标操作）、requestAnimationFrame 分数动画
